# Promotion Manager API

API REST en Go generada por LORD desde los contratos versionados en `.lord/`.
Gestiona un catálogo de promociones persistido en disco y permite que un equipo
autorizador consulte su vigencia, cuotas y descuento. Ya no cotiza carritos ni
aplica promociones.

## Contratos

- `.lord/application.yaml`: entidad, campos, operaciones, política de vigencia y flujos.
- `.lord/contract.yaml`: orden lógico permitido para crear, modificar y consultar promociones.
- `.lord/proposals/` y `.lord/approvals/`: trazabilidad de la revisión que activó ambos contratos.

Los archivos marcados `Code generated by LORD` no se editan directamente. Un
cambio de comportamiento se propone en el contrato, se valida, se aprueba y se
regenera.

## Flujos

**Gestión de catálogo:** crear y modificar promociones administrativas.

**Soporte a autorizaciones:** obtener una promoción, listar el catálogo o
consultar si está vigente en un instante determinado. La respuesta de vigencia
incluye sus características completas.

## Ejecutar

```bash
go run ./cmd/api
```

El servicio escucha en `:8080`.

## Persistencia

El catálogo se guarda en SQLite. La entidad declara `storage: sqlite` en
`.lord/application.yaml` y el contrato fija `./data/promotions.db` como ruta por
defecto, sobrescribible con la variable de entorno `LORD_DATABASE_PATH`. El
servicio crea el directorio y el esquema al arrancar y aplica migraciones
aditivas automáticas; una columna presente en la base pero ausente del contrato
aborta el arranque en lugar de aplicar una migración destructiva. Los datos
sobreviven reinicios y caídas del proceso.

La traza de eventos operacionales expuesta en `/_lord/events` sigue siendo en
memoria: se reinicia con el proceso y no persiste junto con el catálogo.

## Ejemplo

```bash
curl -s http://localhost:8080/v1/promotions \
  -H 'content-type: application/json' \
  -d '{
    "id": "PROMO-12",
    "name": "12 cuotas y 15%",
    "starts_at": "2026-08-01T00:00:00-03:00",
    "ends_at": "2026-09-01T00:00:00-03:00",
    "installments": 12,
    "discount_percent": 15,
    "enabled": true
  }'

curl -s \
  'http://localhost:8080/v1/promotions/PROMO-12/validity?at=2026-08-15T10%3A00%3A00-03%3A00'
```
